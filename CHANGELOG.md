## [0.1.16](https://github.com/Wisdoverse/wisdoverse-forge/releases/tag/v0.1.16) (2026-03-17)

### Features

- **voice:** real-time streaming transcription with multi-provider Voice Gateway (Deepgram, Google Cloud, Azure, AssemblyAI)
- **orchestration:** A2A multi-agent orchestration with BullMQ task dispatch, participant registration, heartbeat, and kanban board
- **observability:** OpenTelemetry distributed tracing added to gRPC PlatformClient with span attributes and error recording
- **migration-058:** full session→agent rename across database schema (tables, columns, indexes, constraints, functions)
- **devenv:** development environment management with container lifecycle, quota governance, and policy-based provisioning

### Refactor

- **rename:** Session → Agent across full stack — API routes (`/api/v1/sessions` → `/api/v1/agents`), database tables, Go platform handler, WebSocket protocol, frontend handlers
- **rename:** orchestration Agent → Participant — API routes (`/api/orchestration/agents` → `/api/orchestration/participants`), database table `agents` → `participants`
- **ws-gateway:** refactored WebSocket gateway naming (sessionId→agentId, broadcastAgentUpdate, matchesAgentSubscription), removed dead connectionCount field, improved enrichEvent with explicit control flow

### Bug Fixes

- **chat:** real-time events dropped by watermark ISO vs numeric comparison
- **orchestration:** task not appearing in kanban after creation
- **orchestration:** added concurrent deletion check (rowCount) in retryTask
- **ws-gateway:** empty catch on ws.close replaced with debug log
- **platform:** TLS cert ENOENT now wrapped with actionable error message
- **otel:** distinguishes ERR_MODULE_NOT_FOUND from real init failures
- **pubsub:** channel mismatch fixed — ws.gateway.ts now subscribes to correct channel

### Security

- **auth:** added AuthGuard to voice controller and plugin controller endpoints
- **ws-gateway:** WebSocket origin validation, rate limiting, message size limits
- **routes:** protected previously unauthenticated endpoints with auth middleware

### Tests

- **migration-058:** added integration test with 47 assertions for session→agent rename migration
- **TurnStreamRenderer:** added unit tests for stream rendering edge cases
- **orchestration:** updated test fixtures for participant rename

## [1.0.0](https://github.com/Wisdoverse/wisdoverse-forge/releases/v1.0.0) (2026-01-15)

### Features

- **visualization:** Three.js workshop scene with ClaudeMon character
- **websocket:** real-time communication gateway with Redis PubSub
- **sessions:** multi-session management via Docker container isolation
- **stations:** 8 station types mapped to Claude Code tools (Bookshelf, Desk, Workbench, Terminal, Scanner, Antenna, Portal, Taskboard)
- **subagents:** Task tool spawn/remove mini-Claudes at portal
- **audio:** Tone.js spatial audio synthesis with distance attenuation
- **voice:** Deepgram speech-to-text integration
- **draw-mode:** hex tile painting with 3D stacking
- **zones:** HexGrid-based zone positioning with attention indicators
- **feed:** activity feed with expandable event details
- **shortcuts:** full keybind system with customization
- **animations:** victory dance on commits, shake on errors
- **resume:** browse and resume previous Claude Code sessions
- **platform:** Rust control plane for containers, git, events, WebSocket, and pool management
- **database:** PostgreSQL persistent storage with 15+ tables
- **storage:** MinIO object storage for attachments
- **deploy:** Docker multi-stage builds with compose profiles

### Security

- JWT authentication with refresh token rotation
- Argon2 password hashing (NIST SP 800-63B compliant)
- input validation with Zod schemas
- CORS configuration with strict origin validation
- rate limiting with Redis sliding window
- login attempt lockout protection
- Sentry error tracking with PII filter

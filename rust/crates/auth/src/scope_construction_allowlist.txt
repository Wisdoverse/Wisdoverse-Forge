# Allowlist of PRODUCTION TenantScope construction sites (ADR 0004). Test
# constructors are NOT listed here: the guard skips #[cfg(test)] blocks and
# /tests/ directories. An entry is either a whole file (`path`) or one function
# (`path::fn_name`); prefer the function form so a new wrapper in an allowed file
# is still flagged. Background work uses TenantScope::for_background and needs
# no entry.
rust/crates/core/src/tenant.rs # The definition of TenantScope and its constructors.
rust/crates/api/src/test_support.rs # Central test-only construction helper; compiled only under cfg(test) or the test-support feature, but it is a separate file, so it is listed explicitly.
rust/crates/auth/src/middleware.rs::from_request_parts # THE auth-middleware constructor: builds the request scope from the validated JWT claims (org/user/axes).
rust/crates/api/src/gateway/ws.rs::ws_handler # WebSocket gateway auth: builds the connection scope from the validated JWT (?token=) before any handler runs, mirroring the HTTP middleware.
